纽约基础套餐普遍标注 1 Gbps Link Speed。它表示虚拟机接入端口上限，不代表你从中国大陆访问时一定可以跑到 1 Gbps。

- 中国大陆本地运营商
- 目标网络
- 国际出口
- 高峰期拥堵
- 路由路径
- 服务器当前负载

所以，端口速度可以作为配置参考，但不能替代线路测试。

### 3. 注意服务是自主管理型

官网明确说明该 VPS 是 self-managed。用户需要自己负责：

- SSH 安全
- 防火墙
- 系统更新
- Web 服务配置
- 数据库维护
- 备份验证
- 日志和资源监控
- 应用漏洞修复

如果你只想购买一个“开箱即用、有人帮忙维护”的托管服务，搬瓦工基础 VPS可能不符合预期。

### 4. 先确定是否需要中国大陆线路优化

这是最容易买错的地方。

如果你真正需要的是纽约位置，选择 New York。
如果你真正需要的是 CN2 GIA，优先选择官方标注 CN2 GIA 的洛杉矶、香港或日本方案。
